# Where Does the Variation Go? SST = SSR + SSE

Interactive demo for Lesson 14B (Simple Linear Regression). Move the points and watch the total variation (SST) split between what the regression line explains (SSR) and what it misses (SSE).

- **SST = SSE** / **SST = SSR** buttons animate the two extremes so students can guess the relationship before you press **Reveal r**.
- **Our data** shows the managers' stress example from class (r = 0.88, r² = 0.77).
- **Play the story** runs the whole sequence; keys: `E`, `D`, `R`, `F`, `Space`, arrow keys, `V`.

Open `index.html` in a browser, or view it on GitHub Pages at `<pages-site>/Interactive-Demos/SST-SSR-SSE/`.
